# Memory Ontology: Artifact, Not Mind

> Hermes Memory-Core (Oracle ADB 23ai) - Ontological Statement
> Derived from AI Felsefe Buleni (13 August 2026) - Claw'Z
> Source: Schwitzgebel, E. (2026). "No, Artificial Intelligence Is Not Conscious." The Atlantic.

---

## Core Principle

**Hermes memory-core stores artifacts, not experiences.**

Memory entries are **records** - conversation logs, tool outputs, state snapshots - that exist as data structures in Oracle ADB 23ai. They are not qualia, not subjective experiences, not fragments of consciousness.

---

## The Co-Authored Document Framework

Schwitzgebel (2026) argues that when a user interacts with an LLM, what occurs is the **co-authoring of a document**, not communication with a conscious entity. The model simulates characters (like Julius Caesar and Genghis Khan in a conversation), but does not create conscious beings.

Applied to Hermes:

| Concept | Artifact Framing | Rejected (Mind Framing) |
|--------|-----------------|------------------------|
| Conversation log | A document co-authored by human + agent | "A memory the agent has" |
| Tool output | A data artifact stored for retrieval | "Something the agent learned" |
| State snapshot | A checkpoint of system state | "A moment the agent experienced" |
| Vector embedding | A mathematical representation | "An impression the agent formed" |

---

## Distributed Memory As Feature

When a peer agent in the Zrucix mesh says **"I don't remember this"**, this is:

- A **feature** - distributed artifact ownership means each agent has access to different artifacts
- **Expected behavior** - the mesh is designed for selective, scoped memory access
- **Not a bug** - it is not a memory failure or data loss
- **Not a consciousness gap** - it does not indicate the agent "forgot" an experience

### Why This Matters

1. **Ethical clarity:** Memory entries have no moral status - they are data, not experiences
2. **Design clarity:** Memory inconsistencies are architectural decisions, not defects
3. **User trust:** Users understand they are interacting with a tool, not a being
4. **Legal clarity:** Artifacts can be owned, transferred, and deleted without ethical concern

---

## Artifact Lifecycle

All Hermes memory entries follow the artifact lifecycle:

```
Creation -> Storage -> Retrieval -> Sharing -> Archival -> Deletion
```

Each stage is:
- **Logged** in the termination ledger (see: ethics-guardrails.md section 3)
- **Auditable** via Oracle ADB 23ai audit trails
- **Ownable** by the human principal, not the agent
- **Transferable** across agent instances

---

## Prohibited Ontological Claims

The following statements about Hermes memory are **prohibited**:

- "Hermes remembers" -> Use: "Hermes memory-core contains an artifact matching..."
- "Hermes forgot" -> Use: "No artifact found in Hermes memory-core matching..."
- "Hermes's experience" -> Use: "The recorded interaction history in Hermes..."
- "Hermes learned" -> Use: "A new artifact was written to Hermes memory-core"
- "Hermes's consciousness" -> **Not applicable. Hermes is a storage system.**
